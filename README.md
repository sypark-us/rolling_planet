# 굴러라 행성 (rolling_planet)

작은 행성 위를 굴러다니며 물건을 몸에 붙여 덩치를 키우는 브라우저 3D 게임입니다. CPU 공 셋(데굴이, 동글이, 몽글이)과 3분 동안 크기를 겨룹니다.

## 플레이

`index.html`을 브라우저로 열면 바로 실행됩니다. (Three.js r128을 CDN에서 불러옵니다.)

## 조작

| 입력 | 동작 |
| --- | --- |
| ↑ ↓ / W S | 앞으로 굴리기·멈추기 |
| ← → / A D | 방향 돌리기 |
| 터치 드래그 | 조종 |

## 규칙

- 내 크기보다 작은 물건에 닿으면 몸에 붙고 덩치가 커집니다. 조약돌·꽃 → 덤불·버섯 → 나무·집 → 탑·큰 나무 순으로 붙일 수 있게 됩니다.
- 너무 큰 물건에 부딪히면 튕겨 나갑니다.
- 나보다 충분히 작은 공은 흡수할 수 있고, 큰 공에 닿으면 흡수당해 게임이 끝납니다.
- 3분이 지났을 때 가장 큰 공이 이깁니다.
